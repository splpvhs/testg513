# 🚀 حزمة تطبيق لعبة الحساب الذكية (GitHub & Web Package)

مرحباً بك! هذه الحزمة مقسمة ومجهزة خصيصاً للرفع والتشغيل المباشر على **GitHub Pages** أو أي استضافة ويب.

## 📂 محتويات الحزمة:
- `index.html`: الصفحة الرئيسية للعبة.
- `css/style.css`: ملف التصميم والألوان والمعرض المتحرك.
- `js/script.js`: ملف البرمجة، الأسئلة، والمحرك المستقل.
- `photos/`: مجلد يحتوي على صور المؤسسة (`photo1.jpg`، `photo2.jpg`، إلخ).
- `audio/`: مجلد يحتوي على الملفات الصوتية الأستوديو:
  - `vrai.mp3`: صوت الإجابة الصحيحة
  - `faux.mp3`: صوت الإجابة الخاطئة
  - `celebration.mp3`: صوت الاحتفال بالنجاح
  - `music1.mp3` إلى `music5.mp3`: مقاطع الموسيقى الخلفية التفاعلية الخمسة

## 🌐 كيفية النشر على GitHub Pages:
1. أنشئ مستودعاً جديداً (Repository) على GitHub.
2. ارفع جميع الملفات والمجلدات المرفقة في هذه الحزمة بنفس الهيكلية.
3. اذهب إلى **Settings** -> **Pages** في GitHub واختر الفرع الرئيسي (`main` or `master`).
4. اضغط **Save**. سيعطيك GitHub رابطاً مباشراً يعمل 100% على جميع الهواتف!
